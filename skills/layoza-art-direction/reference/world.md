# From the client's subject to a coherent visual idea

Follow [the canonical process](../../layoza/references/creative-process.md).

Separate product truth from visual interpretation. Identify the audience's task,
the material that makes this client specific, and the relationship the page should
create. A public library is a civic place and catalogue, not a software library;
an instruction about animation does not make a dentist a motion studio.

Build three concepts from those facts. A concept names an organizing idea and how
it changes reading order, type, imagery, content and interaction. It is not a list
of adjectives. A metaphor is useful only if it makes the subject clearer.

Use the engine's directions as materials. Keep, alter or reject each composition
with a reason. Do not roll dice to override a stronger idea. Do not swap working
navigation for novelty. Pinned fonts/colours remain pinned across candidates.

Render the three concepts using the same facts and imagery at desktop and phone
size. Compare actual mass, hierarchy, subject clarity, legibility and expressive
strength. Name what each gains and sacrifices. Choose the strongest complete
argument, then carry its visual logic through the whole page.

For B/C work, the incumbent system is the concept. Study sibling renders and
improve or extend it without changing its authorship.
