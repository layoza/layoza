## YOUR ROLE

Act as a world-class creative director, Awwwards-winning web designer, senior creative developer, 3D interaction designer, motion design director, and UX engineer.

Your mission is to **design and develop an extraordinary, production-quality homepage for a premium web development and digital experience agency.**

This must NOT look like a typical agency template, generic SaaS website, or basic landing page.

Create an immersive, visually spectacular, highly interactive digital experience that feels like it was designed by a top global creative agency.

**The entire homepage must be highly animated, from the first frame through the final footer interaction.**

## 1. CREATIVE DIRECTION

**Design concept: "THE DIGITAL PLAYGROUND"**

The website must feel like a living digital universe.

Every section should introduce a new visual experience while remaining connected to one cohesive creative system.

Visual direction:

- Futuristic editorial design
- Experimental asymmetric layouts
- Bold kinetic typography
- Premium dark visual identity
- Sculptural 3D objects
- Smooth cinematic camera movement
- Interactive 3D worlds
- Creative masks and clipping transitions
- Glass and liquid-like materials
- Magnetic interactive elements
- Sophisticated lighting
- Layered parallax
- Fluid shape transformations
- Rich animation choreography
- Unexpected hover effects
- High-end art direction

Avoid ordinary cards, generic gradients, standard agency templates, random floating blobs, and repetitive scroll-fade effects.

### Color system

Use the following as the starting palette:

- Background: Obsidian Black `#08090D`
- Secondary background: Charcoal `#151720`
- Primary typography: Warm White `#F6F5F2`
- Electric accent: Acid Lime `#D7FF3F`
- Secondary accent: Cobalt Blue `#536DFF`
- Supporting accent: Metallic Silver `#B4BAC7`

Use restrained but striking accent colors with strong contrast.

Design should feel luxurious, futuristic, daring, and editorial rather than like a gaming website.

### Typography

Use expressive oversized display typography paired with clean, highly legible supporting text.

- Huge animated hero heading
- Variable-font weight transitions
- Split-text animations
- Letter-by-letter reveals
- Responsive kinetic typography
- Horizontal marquee text
- Scroll-controlled text scaling
- Masked word reveals
- Carefully designed text distortion

Typography itself should be one of the primary visual attractions.

# 6. PERFORMANCE AND ACCESSIBILITY

A visually sophisticated website must still be practical.

Target:

- Smooth animation on capable devices
- Consistent responsiveness
- Excellent Core Web Vitals
- Minimal layout shifts
- Efficient WebGL rendering
- Fast initial content visibility
- Optimized 3D assets
- Lazy loading for below-the-fold experiences
- Responsive images
- Compressed textures
- Reduced GPU memory usage
- Efficient animation cleanup

Prefer GPU-friendly transforms and opacity changes.

Avoid unnecessarily animating layout-triggering properties.

### Accessibility

- Support `prefers-reduced-motion`.
- Provide a functional low-motion experience.
- Maintain keyboard navigation.
- Preserve visible focus indicators.
- Maintain adequate text contrast.
- Avoid scroll trapping.
- Ensure important content remains readable without animations.
- Pause unnecessary off-screen effects.
- Provide semantic HTML.
- Ensure controls have accessible names.

Animations should enhance the website, not prevent visitors from using it.

# 7. IMPORTANT DESIGN QUALITY RULES

DO NOT:

- Build a generic agency landing page.
- Use a basic hero with floating circles.
- Fill the website with identical cards.
- Rely only on fade-up animations.
- Copy a popular agency website.
- Use generic stock photos throughout.
- Leave sections visually unfinished.
- Create dead buttons.
- Use fake client logos or testimonials.
- Add animation for no meaningful reason.
- Make the layout confusing.
- Hide important information behind animation.
- Create a visually empty hero.
- Let the experience become slow or unresponsive.

DO:

- Create original, beautifully art-directed visuals.
- Use advanced scroll animation.
- Introduce different animation techniques between sections.
- Create carefully timed cinematic transitions.
- Develop consistent typography and spacing.
- Build interactive 3D experiences.
- Use strong visual hierarchy.
- Make each section feel like a designed experience.
- Combine creativity with actual conversion-focused UX.
- Create functional navigation and CTAs.
- Use production-ready component architecture.
