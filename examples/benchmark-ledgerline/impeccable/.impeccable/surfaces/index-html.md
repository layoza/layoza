## Direction contract

THESIS: Ledgerline is a cheque-and-remittance security document, not a SaaS dashboard. The page is printed in intaglio ink on guilloche-tinted security paper; it refuses the category hero (headline left, floating dashboard screenshot right, logo row below).

OWN-WORLD: Cool mint security-tint ground (#E6EFEA) under fine generated guilloche lines; deep intaglio green (#0D3A2C) owns whole bands; plum (#7B1E3F) is reserved for exceptions/flags; vermilion overprint (#C2401C) is reserved strictly for actions. Perforated stub edges, MICR-style code lines, written-out amounts, engraved Bodoni Moda display, Schibsted Grotesk text, Spline Sans Mono for figures and codes. Rows on fixed columns; nothing in rounded soft cards.

STORY: Visitor sees bank lines clear against invoices with one line flagged, understands "it hands you only the exceptions", prices the saving on a cheque made out to their practice, checks UK hosting and access facts, starts a trial.

FIRST VIEWPORT: Left 5/12: Bodoni headline (~5.2rem desktop), one supporting line, work-email field + vermilion "Start free trial", secondary "See how matching works". Right 7/12: a remittance advice document on security paper with perforated stub; 6 bank-feed rows match to invoice/receipt refs one by one (tick + ref), one row flags in plum ("No match — review"), VAT box 1/4/5 totals at the foot; a generated guilloche rosette seal. The whole first viewport sits on a deep intaglio-green field with the header in mint ink; the remittance document is the one paper object on it.

FORM: Cheque / remittance security print, candidate 6 of my ordered list. seed: none (unavailable)
Raises: (split-flap concourse) rows are entities on fixed columns; state restyles the row, never the grid. (warm consumer canon) one saturated colour, vermilion, only on pressable things. (cyclorama dawn) every state carries a glyph and a word, never colour alone. (silkscreen loft) each guilloche is procedurally generated from its own parameters, a genuine variant per use.
Signature interaction: the savings estimator is a cheque written to the visitor's practice; hours appear in the box and in words on the payee line, updating live; the MICR line encodes the inputs.
Motion grammar: one authored moment, the hero clearing pass (rows tick in sequence, ~2.4s), content visible by default; reduced motion shows the cleared end state.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
