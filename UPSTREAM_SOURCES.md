# Upstream Sources & Feature Reuse Classification

This document records the mandatory upstream repositories researched and inspected for **Layoza**, including exact repository URLs, verified HEAD commit SHAs (inspected on 2026-10-13), SPDX licenses, maintenance status, inspected files/commands/limitations, and legal/technical reuse classifications.

## Classification Legend

- **`directly reusable`**: Permissively licensed (MIT, Apache-2.0, ISC) data, specifications, or algorithms that can be adapted or incorporated with proper license and notice preservation in `THIRD_PARTY_NOTICES.md`.
- **`requires adaptation`**: Permissively licensed concepts, taxonomies, or rules that require architectural translation (e.g., porting Python CSV search or rigid bash scripts into Layoza's unified Rust core and context-sensitive engine).
- **`integration-only`**: External libraries, runtimes, or protocols invoked or generated into target user projects via standard package managers (e.g., Playwright, axe-core, Lighthouse, GSAP, Three.js, Motion, Lenis) rather than forked into Layoza's binary.
- **`reference-only`**: Studied for architectural comparison, taxonomy coverage, or UX inspiration only; no code or protected assets copied.
- **`legally unsuitable`**: Contains Commons Clause, commercial redistribution restrictions, or non-open licenses prohibiting bundling into a competing open-source redistribution product.
