# Example Prompts for AI Coding Agents Using Layoza

Use these prompts in **Google Antigravity**, **Claude Code**, **Cursor**, **Codex**, or **OpenCode** with the Layoza skills and MCP server enabled.

---

## Mode A: New Website from Scratch (With 3 Creative Directions)
> "Use Layoza (`layoza` + `layoza-creative-direction` + `layoza-new-website`) to design and build a flagship marketing page for **Veritas Quantum**, an enterprise cryptographic key-management platform. First run `layoza_recommend_design` for `fintech` and present 3 genuinely distinct creative directions (Swiss Architectural Grid vs Dark Precision Telemetry vs Editorial Sovereign). Implement Direction 1 in semantic HTML/CSS/JS, then verify it across desktop, tablet, and mobile in headless Chromium."

---

## Mode B: Extend an Existing Website Without Breaking Brand DNA
> "We need to add a new **Enterprise SLA & Security Compliance** section and an interactive **Pricing Tier Matrix** to our existing website in `examples/existing-site-preservation`. Use Layoza Mode B (`layoza-extend-website`): first run `layoza_inspect_project` to extract `SITE-DNA.json` and `DESIGN.md`, preserve 100% of our existing `--color-bg-parchment`, `--color-accent-terracotta`, and Cormorant Garamond / DM Sans typography tokens, and verify zero horizontal overflow or contrast regressions."

---

## Mode C: Audit & Improve an Existing Website
> "Run `scripts/browser-qa.mjs` and `layoza verify --auto-repair` on our current landing page. Identify any WCAG 2.2 AA contrast failures, undersized touch targets (`< 24x24px`), or mobile horizontal overflow, apply the bounded auto-repair fixes while keeping our existing visual identity intact, and compare the before/after snapshots."

---

## Mode D: Safe Full Redesign with Baseline Rollback
> "Create a Layoza baseline snapshot (`layoza_create_baseline`) of our current site, then explore a high-craft kinetic agency redesign (`MOTION_INTENSITY=8`, `DESIGN_VARIANCE=8`) using `layoza-animations` and `layoza-redesign`. Ensure every animation honors `prefers-reduced-motion: reduce` and keep the baseline ID ready for instant rollback."

---

## WordPress Gutenberg Block Theme Generation
> "Use `layoza-wordpress` and `layoza generate --framework wordpress-gutenberg` to create a complete WordPress 6.7 Full Site Editing (FSE) Block Theme with `theme.json` v3 fluid typography, semantic color presets, and reusable PHP block patterns (`patterns/hero-section.php`)."
