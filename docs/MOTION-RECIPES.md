# Layoza Motion & 3D Choreography Recipes

All motion recipes are generated by [`crates/layoza-core/src/animation.rs`](../crates/layoza-core/src/animation.rs) via `layoza animate --recipe <id>` or MCP `layoza_generate_animation`.

## Mandatory Engineering Guarantees
Every recipe generated by Layoza enforces:
1. **`prefers-reduced-motion: reduce` Check**: Immediate static fallback when the user prefers reduced motion.
2. **Deterministic Cleanup**: `gsap.context().revert()`, `ScrollTrigger.kill()`, `cancelAnimationFrame()`, or Three.js `geometry.dispose()` / `material.dispose()` / `renderer.dispose()`.
3. **60fps Frame Budget (`<= 16.6ms`)**: Animates GPU-composited `transform` and `opacity` properties only.

## Recipe Catalog

| Recipe ID | Engine | Best For | Key Safeguards |
| :--- | :--- | :--- | :--- |
| `staggered-hero` | GSAP `gsap.context()` / WAAPI | Hero headlines, eyebrow badges, and primary CTAs | Reverts cleanly on React unmount; skips stagger on `prefers-reduced-motion` |
| `scroll-pinned-story` | GSAP `ScrollTrigger` | Multi-step product walkthroughs & scrollytelling | Disables pinning on small mobile viewports (`< 768px`) to preserve native touch scroll |
| `waapi-spring-reveal` | Native Web Animations API | Zero-bundle Astro, HTML, and WordPress sites | Zero external JS dependencies; `fill: "both"` |
| `magnetic-cta` | Vanilla JS + CSS Transform | Agency buttons & tactile interactive controls | Uses `translate3d` and resets on `mouseleave` |
| `view-transition-route` | Native CSS View Transitions API | Multi-page Astro / Next.js / SPA state morphs | Graceful fallback when `document.startViewTransition` is unsupported |
| `threejs-hero-scene` | Three.js / React Three Fiber | 3D spatial stages, shaders, & interactive meshes | Caps DPR at `Math.min(devicePixelRatio, 2)`, pauses via `IntersectionObserver`, disposes GPU memory |
| `lenis-gsap-sync` | Lenis + GSAP Ticker | High-craft editorial/agency sites (`MOTION_INTENSITY >= 7`) | Conditional opt-in only; preserves native keyboard scroll & `data-lenis-prevent` modals |
